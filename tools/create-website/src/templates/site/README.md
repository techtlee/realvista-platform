# site-{{slug}}

The public website of **{{brandName}}**, a REALVISTA client.

Generated by `/create-website` from the REALVISTA site template
(platform `{{platformSha7}}`). The first commit is the template unmodified;
the second makes it standalone and configures it for this client, so every
later change is a visible diff.

## Layout

- `app/`: Next.js routes (one-liners delegating to the theme)
- `site.config.ts`: the client's selection (theme, colourway, sections,
  features). **Generated**: change the provisioning request and regenerate.
- `site.urls.ts`: the canonical and CMS origins `next.config.ts` needs.
  Generated with `site.config.ts`.
- `src/makleri/`: the REALVISTA packages (core, theme kit, theme), copied as
  sources. Fixes arrive as template updates, not as edits here.

## Run locally

```sh
cp .env.example .env.local   # then fill in CMS_API_KEY and REVALIDATE_SECRET
pnpm install
pnpm dev                     # http://localhost:{{sitePort}}
```

The content comes from this client's own backend (`backend-{{slug}}`,
locally on port {{backendPort}}). Secrets live only in `.env.local`, which is
git-ignored.
